# Methods-sources ledger for engine constants (SI Table S4) — revision 2 (v4 engines)

Every numeric constant, default, coefficient, threshold and normalization range in the engines, with the source that states it or an explicit unsourced flag. Rows verified by re-fetch on 2026-09-04 (the provenance pass) are unchanged; the rows added on 2026-09-05 are the constants introduced by the v4 engine revision (`reference/engine_fix_constants.csv`: EPA benefit-per-ton values, eGRID2023 subregion emission rates and resource mixes, AVERT PM2.5 rates, Swedish power-sector intensities, AP-42 formaldehyde factors, Briggs dispersion coefficients, Pope/Krewski/BenMAP concentration-response inputs, monitored PM2.5 backgrounds, Macknick water factors, IPCC/EIA/Lazard power-source parameters). For each added row `engine` is the file that consumes the constant and `scope_detail` gives the code path; `final_tag` is the verified tag from the engine-fix pass. Note that some v3-era rows describing superseded logic (e.g. the `PG_SIGMA` centreline sigmas, the 0.08 g/kWh formaldehyde factor, the 0.001 ug/m3 per tonne dispersion constant, the +50/-500 community anchors) are retained for traceability; the v4 equations that replace them are listed in `S_equations_registry.md`.
